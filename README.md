# Matlock's Tune Shop

A modern, dark-themed marketing website for **Matlock's Tune Shop** — a Calgary-based snowboard tuning service run by Kyle, a technician with 15+ years of experience.

## Tech Stack

- **Next.js 16** (App Router, Turbopack)
- **React 19**
- **TypeScript**
- **Tailwind CSS v4**
- **Montserrat** font (Google Fonts) — matches the bold geometric look of the logo

## Features

- Sticky navbar with smooth-scroll anchor links
- Hero section with a custom hand-drawn-style mountain SVG backdrop
- Services grid: Base Repair, Same-Day Waxing, Top Sheet Repair, Base Grinding
- About section introducing Kyle with key stats
- Contact section + footer linking Instagram, TikTok, and email
- Fully responsive, dark-mode aesthetic matching the logo's black & white palette
- SEO metadata and Open Graph tags

## Getting Started

```bash
npm install
npm run dev      # start dev server at http://localhost:3000
npm run build    # production build
npm run start    # run production server
npm run lint     # eslint
```
